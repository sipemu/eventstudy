<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner -> gh-pages branch | The workflow commits built site HTML to gh-pages using GITHUB_TOKEN; a mis-scoped token or third-party action could write beyond intent. |
| r-lib/actions + JamesIves deploy action (third-party GitHub Actions) | Pinned external CI actions execute in the runner with repo-write scope. |
| Network-touching vignettes -> external data sources at build time | If a vignette evaluated a live download during the docs build, a transient outage would break CI (availability). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Elevation of Privilege | pkgdown.yaml GITHUB_TOKEN scope | medium | mitigate | Declare least-privilege top-level `permissions: contents: write` only (no packages/pages/id-token write); Task 1 verify asserts contents:write and nothing broader is added. |
| T-12-02 | Tampering | Third-party GitHub Actions (r-lib/actions@v2, JamesIves/github-pages-deploy-action@v4) | medium | accept | Use the same widely-adopted r-lib/actions majors already trusted in R-CMD-check.yaml; JamesIves action is the r-lib-recommended deploy action. Pinned to major tags consistent with existing repo practice; upstream is out of our control (constraint: cannot fix upstream). |
| T-12-03 | Denial of Service | Network-touching vignettes during CI docs build | medium | mitigate | Both data-download.Rmd and introduction.Rmd set eval = FALSE globally so no build-time network call exists (Task 2); a source outage cannot fail the docs build. |
| T-12-04 | Information Disclosure | CRAN source tarball leaking site scaffolding | low | mitigate | .Rbuildignore excludes _pkgdown.yml/docs/pkgdown; Task 3 tarball verify fails if any leak into the built tarball. |
| T-12-SC | Tampering | npm/pip/cargo installs | n/a | accept | No package-manager installs in this phase — only GitHub Actions marketplace actions (covered by T-12-02) and R CRAN/RSPM packages (pkgdown) installed by the standard r-lib setup step. No [ASSUMED]/[SUS] package-legitimacy checkpoint required. |
