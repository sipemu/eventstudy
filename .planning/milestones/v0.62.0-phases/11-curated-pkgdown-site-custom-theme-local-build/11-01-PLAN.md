- NAMESPACE currently has 74 `export()` entries and 12 `S3method()` entries.

  under `reference:`. Non-exported `.Rd` topics (base classes, package doc, KB constants)

  it is NOT `export()`'d. Whether pkgdown warns about it is version-dependent — the
  executor MUST resolve this empirically during the audit (Task 2), not by assumption.
- The 18 vignette files in `vignettes/*.Rmd` match the 18 articles enumerated in the
  UI-SPEC exactly (confirmed by directory listing).
- `README.md` and `NEWS.md` both exist at the package root.

The AUTHORITATIVE audit source is the live build output, NOT any pre-computed symbol
count. The UI-SPEC's 76-symbol grouping is the intended organization; the actual

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-11-03 | Denial of service | Build-time font CDN fetch on offline machine | low | accept | display=swap degrades to system fonts; site still builds. Network-safe vignette handling is deferred to Phase 12 (BUILD-02) |
