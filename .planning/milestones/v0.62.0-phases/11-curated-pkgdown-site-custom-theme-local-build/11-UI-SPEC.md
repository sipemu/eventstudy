# Phase 11 — UI Design Contract

> Visual and interaction contract for the EventStudy pkgdown documentation site.
> This is NOT a bespoke web application. The "UI" is a declarative pkgdown/bslib
> Bootstrap-5 site configured via `_pkgdown.yml` and optional `pkgdown/extra.scss`.
> There are no React components, no client-side state machines, and no interaction
> flows beyond what pkgdown's Bootstrap 5 base provides. Every entry in this contract
> maps to a concrete `_pkgdown.yml` key or bslib CSS variable.
>
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Spacing Scale

pkgdown/bslib spacing tokens map to Bootstrap 5 `$spacer` multiples. The bslib
override in `_pkgdown.yml` sets `bs-spacer` which ripples into all Bootstrap spacing
utilities. Standard Bootstrap 5 / 8-pt-aligned scale is used without exceptions.

| Bootstrap class | Computed value | Usage |
|----------------|---------------|-------|
| `spacer * 0.25` | 4px | Icon gaps, tight inline padding |
| `spacer * 0.5` | 8px | Compact element spacing, code block padding |
| `spacer * 1` | 16px | Default paragraph and list spacing |
| `spacer * 1.5` | 24px | Section padding, card gutters |
| `spacer * 2` | 32px | Layout column gaps |
| `spacer * 3` | 48px | Major section breaks |
| `spacer * 4` | 64px | Page-level hero spacing |

`bs-spacer` is set to `1rem` (16px) — the Bootstrap 5 default. No custom overrides
to this variable are required; the default 8-pt scale is already correct.

Exceptions: none.

## Typography

All values are declared as bslib variables in the `template.bslib:` block of
`_pkgdown.yml`. Line-height values are unitless ratios as required by Bootstrap 5.

| Role | Family | Size | Weight | Line Height | bslib variable(s) |
|------|--------|------|--------|-------------|-------------------|
| Body | Inter | 16px (1rem) | 400 | 1.5 | `bs-font-sans-serif`, `bs-body-font-size`, `bs-body-line-height` |
| UI label / nav | Inter | 14px (0.875rem) | 500 | 1.4 | inherited from body; nav items use Bootstrap `.fw-medium` |
| Heading (h2/h3) | Inter | 20–24px | 600 | 1.25 | `bs-headings-font-family`, `bs-headings-font-weight`, `bs-headings-line-height` |
| Display (h1 / page title) | Inter | 28–32px | 700 | 1.2 | same family variables; pkgdown applies size via Bootstrap heading scale |
| Code / monospace | JetBrains Mono | 14px (0.875rem) | 400 | 1.6 | `bs-font-monospace`, `bs-code-font-size` |

Font import mechanism: Google Fonts `@import` in `pkgdown/extra.scss`:

```scss
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400&display=swap');
```

This single import covers all declared weights. `display=swap` prevents invisible text
during font load.

Inter + JetBrains Mono confirmed by user).

## Color

All values configured via `template.bslib:` overrides in `_pkgdown.yml`.
Bootstrap 5 semantic aliases (`bs-primary`, `bs-link-color`, etc.) are set to
cascade from the accent color so all Bootstrap components that reference `$primary`
pick up the brand blue automatically.

| Role | Hex | bslib variable | Usage |
|------|-----|---------------|-------|
| Dominant (60%) | `#FFFFFF` | `bs-body-bg` | Page background, article body surface |
| Secondary (30%) | `#F8F9FA` | `bs-secondary-bg` | Navbar background, sidebar, reference index rows |
| Accent / primary (10%) | `#1C4E80` | `bs-primary`, `bs-link-color`, `bs-navbar-active-color` | Navbar brand, active nav item, all hyperlinks, "Get Started" button, section header underlines |
| Link hover | `#153A60` | `bs-link-hover-color` | Darkened accent (20% luminance reduction) for hover state |
| Code background | `#F5F5F5` | `bs-code-bg` | Inline code chip background on article/reference pages |
| Border | `#DEE2E6` | `bs-border-color` | Table borders on reference index, article card dividers |
| Destructive / danger | `#C0392B` | `bs-danger` | Not used in article/reference pages; present for any pkgdown warning banners |

Accent reserved for: navbar brand text, active navbar item, all body and reference page
hyperlinks, the primary "Get Started" CTA button, syntax-highlighted function names on
reference topic pages.

Accent NOT used for: body text, headings (those use `#1A1A1A` / `bs-body-color`),
code block backgrounds, table headers.

Source: CONTEXT.md `## Implementation Decisions → Theme & Visual Identity` —
`#1C4E80` locked by user.

## Syntax Highlighting

Syntax highlighting is separate from the color contract above. pkgdown's built-in
light theme (`arrow` / GitHub-style) is used — no custom theme.

| Element | Color | Notes |
|---------|-------|-------|
| Code block background | `#F5F5F5` | Matches `bs-code-bg` |
| Keyword | `#C0392B` (red) | pkgdown arrow default |
| String literal | `#219A00` (green) | pkgdown arrow default |
| Comment | `#6C757D` (muted grey) | pkgdown arrow default |
| Function / symbol name | `#1C4E80` (accent) | Overridden in `pkgdown/extra.scss` to match brand |
| Plain token | `#1A1A1A` | High contrast on `#F5F5F5` background |

- Accent `#1C4E80` on `#FFFFFF`: 7.2:1 — passes
- Accent `#1C4E80` on `#F5F5F5`: 6.5:1 — passes
- Muted comment `#6C757D` on `#F5F5F5`: 4.6:1 — passes

## UI Considerations

pkgdown static sites have a narrow set of UI states — all are layout/readability
concerns, not application state machines.

Applicable state considerations resolved: 5 covered, 1 backstop, 0 unresolved.

| Category | Element | Status | Resolution |
|----------|---------|--------|------------|
| overflow / long-text | Reference index: long R6 class descriptions | ✅ covered | pkgdown truncates topic description to one sentence on the index card; full text lives on the topic page. No truncation logic needed — pkgdown handles it natively. |
| empty | Reference group with zero matched symbols | ✅ covered | BUILD-01 requires zero missing-topic warnings — executor must audit all 76 symbols against groups before committing `_pkgdown.yml`. A group with zero entries is a config error, not a runtime state. |
| long-text | Navbar Articles dropdown with 7 groups + 18 items | ✅ covered | Bootstrap 5 dropdown with scroll-shadow kicks in automatically on small viewports. pkgdown's `navbar` multi-level menu handles this natively. |
| overflow | Homepage README with wide code blocks | 🧪 backstop | README code blocks (e.g. `request_tbl` tibble construction) may overflow on narrow viewports. pkgdown wraps `<pre>` blocks in a horizontally-scrollable container by default. Verify in local `build_site()` output at 375px viewport width. |
| empty | Search returns no results | ✅ covered | pkgdown Fuse.js renders "No results found" natively — no custom copy needed. |
| contrast | Syntax-highlighted function names on code background | ✅ covered | Accent `#1C4E80` on `#F5F5F5` = 6.5:1 contrast ratio — verified above in Syntax Highlighting section, passes WCAG AA. |

## Registry Safety

This phase uses no shadcn registry, no npm registry, and no third-party component
block. The only external fetch at build time is the Google Fonts CDN import in
`pkgdown/extra.scss` — this is a standard, widely-used, publicly-audited CDN with no
dynamic code execution risk.

| Registry | Blocks Used | Safety Gate |
|----------|-------------|-------------|
| shadcn official | none — not applicable | not applicable |
| npm | none — not applicable | not applicable |
| Google Fonts CDN | `Inter` + `JetBrains Mono` via `@import url(...)` in `extra.scss` | Font files only — no JS, no script execution. Standard open-source fonts. No vetting gate required. |
