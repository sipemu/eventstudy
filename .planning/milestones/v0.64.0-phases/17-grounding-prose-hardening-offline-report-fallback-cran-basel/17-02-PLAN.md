<objective>
Expand the proven tracer with the GROUND prose grounding scanner: extend the
runtime grounding guard so it catches a fabricated numeric literal sitting in
free-text narrative prose (not just in structured evidence[] arrays). On a
fabricated number the offending section is dropped and exactly one warning is
emitted — mirroring the existing drop-and-keep contract — and the unverified number
is never emitted into rendered output.

Purpose: This is the milestone core-value guarantee. It must be consistent with the
single warning-emitting-point discipline of .validate_grounding().

Output: Four internal functions in R/advise.R and a GROUND-01/02/03 regression test
file locking the report-path invariant.
</objective>
