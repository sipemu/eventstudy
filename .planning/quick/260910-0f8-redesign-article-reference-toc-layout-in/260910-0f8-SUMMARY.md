# Phase quick-260910-0f8 Plan 01: Redesign Article/Reference ToC Layout Summary

## One-liner

CSS grid centered 900px reading column with 18rem sticky right-margin ToC on >=1200px screens; tinytable tables scroll in-box via overflow-x:auto; full pkgdown site rebuilt.

## What Was Built

### Task 1: Rework extra.css (commit aaca35d)

Three coordinated changes to `pkgdown/extra.css`:

1. **Container selector update** — replaced `.container.template-article, .container.template-reference { max-width: 1560px }` with a new block covering `.container.template-article`, `.container.template-reference-topic`, and `.container.template-reference` at `max-width: 1600px`. Updated comment explains WHY: navbar/header stay at BS5 default ~1320px so the body centers rather than running wider than the chrome. BS `.container` margin:auto handles centering — no float/margin overrides added.

2. **Responsive grid block** — new `@media (min-width: 1200px)` block targeting `.template-article .row` and `.template-reference-topic .row`: `grid-template-columns: 1fr minmax(0, 900px) 1fr` with `column-gap: 2rem; align-items: start`. `#main` placed in `grid-column: 2` (`max-width: 900px; width: 100%`); `.col-md-3` in `grid-column: 3` (`width: 18rem; max-width: 18rem; justify-self: start`). `#toc` set to `position: sticky; top: 1rem`. Scoped to article/reference-topic only — reference index (`.template-reference-index`) and home (`.template-home`) are untouched. Below 1200px the block does not apply; pkgdown's default flex row remains fallback.

3. **tinytable overflow block** — unconditional (no media gate): `#main .table.tinytable, #main table.tinytable { display: block; overflow-x: auto; max-width: 100% }`. Applied on all screen widths so narrow screens also benefit.

**Preserved rules verified**: `.page-header .logo { display: none }`, `.template-home .col-md-9`, all `.es-gallery` / `.es-tag` / `.es-section-heading` CSS.

**ASCII-clean fix**: The original file had non-ASCII U+2500 box-drawing characters (`──`) in two comment lines (gallery grid, method tags). These were replaced with ASCII `==` / `=` equivalents as part of making the whole file ASCII-clean per task requirements.
