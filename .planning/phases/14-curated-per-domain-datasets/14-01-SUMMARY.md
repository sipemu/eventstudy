# Phase 14 Plan 01: Curated Per-Domain Datasets Summary

**One-liner:** AAPL/MSFT/GOOGL Q1 2023 earnings-beat panel frozen via live Yahoo Finance fetch, documented with dieselgate-pattern roxygen, pipeline-proven to finite CAAR, and CRAN-clean.

## What Was Built

Three new artifacts completing the earnings_surprises dataset pipeline for Phase 16:

1. **data-raw/earnings_surprises.R** — reproducible 111-line provenance script following dieselgate.R structure exactly: provenance header, `lapply` firm fetch, separate index fetch, 9-column request tibble, list assembly, `usethis::use_data(overwrite=TRUE)` freeze.

2. **data/earnings_surprises.rda** — 6.0 KB bzip2-compressed frozen snapshot. 813 firm rows (AAPL/MSFT/GOOGL stacked) + 271 S&P 500 index rows over 2022-06-01 to 2023-06-30. Three-row request tibble with `event_date` in `"%d.%m.%Y"` format.

3. **R/data-earnings-surprises.R** — 88-line roxygen data doc matching R/data-dieselgate.R section-for-section: `@format` with `\describe{\item{}}`, `@details` with `\itemize`, `@source`, `@examples \donttest{}` (full pipeline), `@docType data`, `@keywords datasets`, `@name earnings_surprises`, `@usage data(earnings_surprises)`, bare-string sentinel `"earnings_surprises"`.

4. **data-raw/DATA-SOURCES.md** — Two-row provenance registry: dieselgate (9.1 KB, 2026-09-04 access) and earnings_surprises (6.0 KB, 2026-09-05 access). Excluded from CRAN tarball by pre-existing `^data-raw$` .Rbuildignore rule.

5. **man/earnings_surprises.Rd** — generated by `devtools::document()` from the roxygen doc above.
