# Phase 20 — UI Design Contract: Brand & Visual Identity

> Visual and interaction contract for the EventStudy R package brand identity and pkgdown
> documentation site. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This is not a web-app frontend phase. The "UI surfaces" are:
> 1. The EventStudy **logo + hex sticker** (SVG artwork: CAR-curve crossing the event line at t=0).
> 2. The **pkgdown site** theme: palette, typography, navbar-with-logo, home card gallery, numeric-badge cards, Open Graph card, favicons.
> 3. The **README** badge row + logo placement.
>
> Plot theming (`theme_eventstudy()`, `es_colours`) is out of scope — that is Phase 21.
> Report aesthetics are Phase 22.

## Logo & Hex Sticker Contract

### Logo Motif

A cumulative-abnormal-return (CAR) curve crossing a vertical event line at t=0. The curve starts
below the baseline (negative pre-event drift), crosses zero at t=0, and rises above (positive
post-event effect). The event line is a thin vertical stroke in primary blue. The curve is drawn in
primary blue with neutral foreground. Background: white (`#ffffff`).

### SVG Geometry (logo.svg — source)

- **Canvas:** 100×100 viewBox (square, scales to any size).
- **Background:** White rectangle 100×100, rounded corners 8px radius.
- **Event line:** Vertical stroke x=50, y=10 to y=90, stroke `#2563eb`, stroke-width 1.5, opacity 0.4.
- **CAR curve:** A smooth cubic Bézier path. Control points (approximate, executor adjusts for visual
  balance): start (10, 68) → through (30, 62), (40, 38) → cross event line at (50, 30) → through (60, 22),
  (80, 18) → end (92, 16). Stroke `#2563eb`, stroke-width 3, fill none, stroke-linecap round.
- **t=0 dot:** Circle cx=50, cy=30, r=4, fill `#2563eb`.
- **Baseline:** Horizontal line y=70, x=10 to x=90, stroke `#94a3b8` (neutral-400), stroke-width 1,
  stroke-dasharray "4 3", opacity 0.6.
- **No text inside the logo mark** (text is added only in the hex sticker via hexSticker).

### man/figures/logo.png (tarball-safe export)

- Render `logo.svg` at 240×240 px via `rsvg::rsvg_png()` (or Inkscape CLI).
- Target file size: < 50 KB (assert in CI with `file.size("man/figures/logo.png") < 51200`).
- No alpha-channel issues — white background is baked in.
