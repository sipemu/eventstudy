# Phase 21 Plan 01: Shared Theme & Plot Aesthetics Summary

Established one exported, colorblind-safe visual language for every EventStudy plot: new `R/theme.R` exports `theme_eventstudy()` (Okabe-Ito-styled composable ggplot2 theme, centred title, bottom legend, slate gridlines) and `es_colours` (12 named hex roles anchored on brand blue `#2563eb`), plus an internal `.style_plotly()` helper; all four plot helpers in `R/plotting.R` (`.plot_single_event`, `.plot_multi_event`, `plot_diagnostics`, `plot_stocks`) now draw colours/theme from these symbols instead of the 14 scattered `steelblue`/`red`/`grey40`/`blue`/`"grey"` literals — aesthetics-only, plot structure untouched.

## What Was Built

- **R/theme.R** — `es_colours` (exported, roxygen-documented named char vector, length 12, all valid hex, `primary == "#2563eb"`), `theme_eventstudy(base_size = 11, base_family = "")` (exported; returns `theme_minimal() + theme(...)`, never mutates the session theme), `.style_plotly(p)` (internal `@noRd`; horizontal legend, white backgrounds, device-default font).
- **R/plotting.R rewire** — every previously hardcoded colour maps to an `es_colours["<role>"]` reference; the three ggplot helpers apply `theme_eventstudy()` (6 applications: single-event + multi-event + 4 diagnostics sub-plots); `plot_stocks()` `vline()` default and explicit `add_trace` line colour pull from the palette and the per-symbol plot is piped through `.style_plotly()`. No geom/aes/labs/alpha/bins/linetype/subplot/type/mode/shapes changes.
- **tests/testthat/test_theme.R** — 3 structural tests (theme returns theme/gg; base_size/base_family accepted; es_colours is non-empty named valid-hex with `primary == "#2563eb"`).
- **DESCRIPTION** — `tinytable`, `patchwork`, `ragg` added to Suggests (landed-but-unused this phase; Phase 22 consumes them). No new Imports.
- **_pkgdown.yml** — `theme_eventstudy` + `es_colours` surfaced at the top of the "Plotting" reference group; group `desc` updated.
- **NAMESPACE + man/** — regenerated by roxygen2 (`export(es_colours)`, `export(theme_eventstudy)`, two new Rd files).
