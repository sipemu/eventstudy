<objective>
Establish one exported, colorblind-safe visual language for every EventStudy plot: a new `R/theme.R` exporting `theme_eventstudy()` (a composable ggplot2 theme) and `es_colours` (an Okabe-Ito named palette anchored on brand blue `#2563eb`), then route it through all four plot helpers in `R/plotting.R` — the three ggplot helpers (`.plot_single_event`, `.plot_multi_event`, `plot_diagnostics`) apply the theme and palette by default, and the plotly `plot_stocks()` reuses the same `es_colours` values (colours/font/legend only, structure untouched). Add `tinytable`, `patchwork`, `ragg` to DESCRIPTION Suggests (landed-but-unused this phase; used in Phase 22).

Purpose: Kills scattered hardcoded colour literals (`steelblue`/`red`/`grey40`/`blue`/`"grey"`) so R plots read as part of the eventstudy.de ecosystem, and gives package users a public `theme_eventstudy()` + `es_colours` they can reuse. Implements D-locked decisions from 21-CONTEXT.md (palette roles, theme scope, plotly parity, Suggests-only additions).

Output: `R/theme.R`, `tests/testthat/test_theme.R`, rewired `R/plotting.R`, updated `DESCRIPTION` + `_pkgdown.yml`, regenerated `NAMESPACE` + `man/`.
</objective>
