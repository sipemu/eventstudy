<objective>
Add the additive `run_event_study(..., report = TRUE)` convenience (REPORT-02): a `report = FALSE`
default plus a `report_args = list()` passthrough, where the omitted/`FALSE` path is byte-identical to
the prior release and the `TRUE` path renders a report via `es_report()`, attaches the path(s) as
`attr(task, "report_path")`, emits one `message()`, and still returns the task.

Purpose: Surface one-call reporting inside the standard pipeline without changing the return type or
touching the byte-identical valid-input contract that the milestone requires.

Output: `run_event_study()` extended in `R/execute.R` (roxygen updated for the two new params) plus a
new test file `tests/testthat/test_run_event_study_report.R`.
