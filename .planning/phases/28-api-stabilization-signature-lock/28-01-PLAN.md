<objective>
Audit the full public API signature surface for inconsistency (argument names, order,
defaults), reconcile the outliers IN PLACE with backward-compatible shims, and stand up
the formal deprecation lifecycle (base `.Deprecated()` + optional `lifecycle` shim, NEWS
discipline) that those shims and all future renames use.

Purpose: This is the reconciliation that must land BEFORE the API snapshot (plan 03) is
captured, so the snapshot pins the *final consistent* surface, not an outlier-ridden one.
Every rename is behavior-preserving on valid inputs — the 400+ test suite stays green.
Output: 28-API-AUDIT.md (the auditable record), R/deprecation.R (the shim mechanism),
reconciled signatures in R/execute.R (and any other outlier files the audit finds), NEWS.md
entries, and a deprecation regression test.

Implements APIS-01 (align-in-place-now per D: Signature Reconciliation) and APIS-04
(deprecation lifecycle per D: Deprecation Lifecycle).
</objective>
