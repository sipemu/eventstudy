- **3 outliers scheduled-for-deprecation**: `bootstrap_test.statistic` (unique "both" value creates confusion with hypothesis-testing concept), `export_results.which` (base R convention; style preference, not error), options namespace (`eventstudy.verbose` vs `EventStudy.*` — would break .Rprofile users without a two-phase approach)

- **Rd param: `\emph{Deprecated.}` not `\lifecycle{}`** — the `\lifecycle{}` macro is only rendered correctly when lifecycle is loaded/imported; using it in Rd for a Suggests-only package causes `unknown macro` build WARNING
