<objective>
Add return-shape contracts that lock the column names/types/shapes of the pipeline's result
tibbles, in a new `R/shape_contracts.R` sibling to `R/contract.R`, opt-in via a package
option and DEFAULT-OFF, warning (never erroring) on mismatch.

Purpose: catch accidental shape drift (a renamed/dropped/retyped result column) during
development and CI without ever changing valid-input behavior — the check only runs when a
developer explicitly opts in. Lands AFTER the signature reconciliation (plan 01) and BEFORE
the snapshot (plan 03).
Output: R/shape_contracts.R, the `EventStudy.shape_contracts` option, the pipeline hook,
and a test covering valid + degenerate shapes for both single-event and multi-event tibbles.

Implements APIS-02 (per D: Shape Contracts).
</objective>
