# Format method for EventStudySummary

Builds the character vector rendered by `print.EventStudySummary` (one
element per output line). See
[`print.EventStudySummary`](https://sipemu.github.io/eventstudy/reference/print.EventStudySummary.md).

## Usage

``` r
# S3 method for class 'EventStudySummary'
format(x, ...)
```

## Arguments

- x:

  An EventStudySummary object.

- ...:

  Additional arguments (unused).

## Value

A character vector, one element per printed line.
