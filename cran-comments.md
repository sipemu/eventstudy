## Resubmission (previously archived 2024-04-20)

This package was archived on CRAN on **2024-04-20** at version **0.39.2**. The
stated reason was **"issues were not corrected despite reminders."** The
underlying findings were all NOTE-level issues on the original EventStudyTools
web-API-client design: undocumented Rd arguments (`doHttrRequest.Rd`,
`errorMessage.Rd`, `isError.Rd`), an installed size of ~7 MB, several unused
imported packages (`RColorBrewer`, `curl`, `scales`, `stringr`), and undeclared
R6 in Rd cross-references.

The current submission (v0.66.0) is a **complete, ground-up rewrite**. The old
web-API-client design has been entirely replaced by a self-contained, composable
R6 pipeline:

```
prepare_event_study()  ->  fit_model()  ->  calculate_statistics()
```

The class of issues that led to archival has been resolved:

* All exported functions carry complete Rd documentation (`@param`, `@return`,
  `@examples`), and `R CMD check --as-cran` reports no missing-documentation or
  documentation-mismatch findings.
* The source package is ~1.9 MB (well under the 5 MB guideline). The installed
  size is dominated by the pre-built vignette HTML under `inst/doc/`.
* All previously-unused imports have been removed. Optional packages
  (`rugarch`, `rmgarch`, `did`, `DIDmultiplegt`, `didimputation`, `DT`, and
  others) are declared in **Suggests** and each is guarded by
  `requireNamespace()` at its call site; none is a hard dependency.
* The `NAMESPACE` is auto-generated by roxygen2 with no undeclared
  cross-references.

The archived 0.39.2 and the current 0.66.0 share only the package name; the
implementation, exported API, and design are substantially different. We
acknowledge the prior archival and believe this rewrite resolves the class of
issues that led to it.

## Examples policy

Examples that are slow or data-dependent but otherwise safe (no network, no
credentials, `tempdir()`-only writes) use `\donttest{}` and are self-contained
via the bundled `dieselgate` dataset. Only the two LLM-provider examples
(`AnthropicProvider`, `OpenAICompatProvider`), which genuinely require a network
connection and API credentials, use `\dontrun{}`. No example accesses the
network by default or writes outside `tempdir()`.
