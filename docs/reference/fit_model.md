# Train the defined model on each event and calculate the abnormal return.

Train the defined model on each event and calculate the abnormal return.

## Usage

``` r
fit_model(task, parameter_set)
```

## Arguments

- task:

  The event study task

- parameter_set:

  The parameter set that defines the event study.

## Value

task
