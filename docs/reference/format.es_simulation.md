# Format method for es_simulation objects

Builds the character vector rendered by `print.es_simulation` (one
element per output line).

## Usage

``` r
# S3 method for class 'es_simulation'
format(x, ...)
```

## Arguments

- x:

  An object of class `"es_simulation"`.

- ...:

  Additional arguments (unused).

## Value

A character vector, one element per printed line.
