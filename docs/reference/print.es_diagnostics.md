# Print method for es_diagnostics objects

Prints a concise summary of the diagnostics, following the package
convention of `print.es_simulation` and `print.es_cross_sectional`.

## Usage

``` r
# S3 method for class 'es_diagnostics'
print(x, ...)
```

## Arguments

- x:

  An object of class `"es_diagnostics"`.

- ...:

  Additional arguments (ignored).

## Value

Invisibly returns `x`.
