# Format method for es_diagnostics objects

Builds the character vector rendered by `print.es_diagnostics` (one
element per output line). See
[`print.es_diagnostics`](https://sipemu.github.io/eventstudy/reference/print.es_diagnostics.md).

## Usage

``` r
# S3 method for class 'es_diagnostics'
format(x, ...)
```

## Arguments

- x:

  An object of class `"es_diagnostics"`.

- ...:

  Additional arguments (ignored).

## Value

A character vector, one element per printed line.
